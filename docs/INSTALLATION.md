# 安装与首次使用

[返回首页](../README.md)

## 下载哪个文件

在本仓库的 [Releases](https://github.com/fcwll666/CampusRelink/releases) 中选择已发布版本，下载 `CampusRelink-1.0.3-win-x64.zip`。不要把 GitHub 的 **Code → Download ZIP** 源码包当作可运行软件；如果尚无 Release，可以按[开发说明](DEVELOPMENT.md)自行构建。

| 条件 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11，64 位 |
| 运行环境 | .NET Framework 4.8 |
| 账号 | 学校提供的一组校园网用户名与密码 |
| 网络 | 已接入校园网，或已有可连接的 Windows Wi-Fi 配置 |

程序目前未签名。请核对下载来源；发行包中的 `SHA256SUMS` 可用于检查文件完整性。

## 四步开始

1. **解压到固定目录。** 双击 `CampusRelink.exe`。首次打开只显示配置界面，不注册自启，也不开始后台连接。
2. **填写校园网账号和密码。** 默认认证接口为 `http://net.njucm.edu.cn/api/portal/v1/login`。南京中医药大学用户通常保留该值；其他环境先阅读[协议适配范围](PORTAL-CONFIGURATION.md)。
3. **选择连接方式。** 已连接 Wi-Fi 或网线、只需要自动认证时，取消「自动连接 Wi-Fi」。需要软件重连指定无线网络时，先在 Windows 中连接并保存该网络，再点「搜索 Wi-Fi」并选择它。
4. **点击「保存并启用」。** 程序保存配置、启动后台，并注册当前用户登录 Windows 后自动运行。仅想验证账号时可点「测试登录」；它会提交真实认证请求，但不会启用自启。

默认认证接口使用 HTTP，认证内容未经传输加密。如果学校提供兼容的 HTTPS 接口，可手动修改；程序正常验证 HTTPS 证书。

## 日常操作

| 操作 | 结果 |
| --- | --- |
| 点击窗口关闭按钮 | 收入托盘，后台继续运行 |
| 双击托盘图标 | 恢复主界面 |
| 托盘菜单「退出」 | 停止后台并退出，保留开机自启 |
| 主界面「停止后台」 | 停止后台，同时移除本工具的开机自启 |
| 修改密码后保存 | 用新密码替换旧密码，再显示固定 15 个星号 |

保存后的 `***************` 是固定占位显示，与真实密码的长度无关。保持占位提示且用户名不变时，会继续使用原密码；更换用户名时需要重新输入密码。

## 两个可选开关

**强连接**用于尝试恢复被关闭的无线开关等状态。启用被禁用的无线网卡需要管理员权限，应用会说明原因并请求一次系统授权，随后由当前用户的最高权限计划任务启动。

**开机代理修复**用于处理代理软件未正常退出而留下的无效本机手动代理。仅在 Windows 开机后前 5 分钟内的自启阶段检查一次；前三次门户探测连续失败，并确认代理端口持续无监听等条件满足后，才备份设置、关闭手动代理并恢复自动检测。日常运行中的网络中断不会触发代理修改。详细边界见[常见问题](FAQ.md#开机代理修复会影响正在使用的代理吗)。

## 从 CampusFlow Community 升级

先从托盘退出旧通用版，再解压并运行新版。原有账号、密码和设置继续保存在 `%LOCALAPPDATA%\CampusFlowCommunity\`，无需手动迁移。

点击「保存并启用」更新启动配置。普通登录自启会更新到新程序位置；如果最高权限任务仍指向旧程序，应用会提示通过管理员授权更新同一任务。取消授权时旧任务保持原路径，确认更新成功前应保留旧程序目录。

这套兼容目录与内部任务名保留旧品牌名称，属于正常情况。

## 卸载

先点击「停止后台」并处理应用显示的任务移除授权，再从托盘退出，最后删除解压目录。若还需要删除本机账号与配置，可在退出后手动删除 `%LOCALAPPDATA%\CampusFlowCommunity\`；此操作会清除已保存设置。

遇到问题请阅读[常见问题](FAQ.md)；反馈前请去除日志中的个人信息。
