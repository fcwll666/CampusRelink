# CampusRelink 1.0.3

校园网自动认证与断线重连工具，适用于 Windows 10 / 11 x64，需要 .NET Framework 4.8。

本软件默认适配南京中医药大学的校园网认证。使用一组校园网账号密码，默认接口为 `http://net.njucm.edu.cn/api/portal/v1/login`；接口可修改，内置认证协议的适用范围见[认证配置](PORTAL-CONFIGURATION.md)。默认 HTTP 接口的认证内容未经传输加密。

## 开始使用

1. 将压缩包解压到固定目录，运行 `CampusRelink.exe`。
2. 填写校园网账号与密码，核对默认认证接口。
3. 已接入校园 Wi-Fi 或网线、只需要自动认证时，取消「自动连接 Wi-Fi」。需要软件重连指定 Wi-Fi 时，先在 Windows 中连接并保存该网络，再点「搜索 Wi-Fi」选择它。
4. 点击「保存并启用」启动后台，并启用当前用户登录 Windows 后自动启动。首次打开界面不会自动开始连接。

保存密码后显示固定 15 个星号 `***************`，不代表真实密码长度；直接输入新密码可替换。更换用户名时必须输入新密码。

## 日常操作

- 关闭窗口：收进托盘，继续后台运行。
- 双击托盘：恢复主界面。
- 托盘「退出」：停止后台并退出，保留开机自启。
- 「停止后台」：停止后台并移除本工具自启。
- 「测试登录」：向配置的接口提交真实认证请求，不启用自启。

强连接模式可能请求管理员授权。开机代理修复只在开机后前 5 分钟内的自启阶段、连续门户失败且本机代理端口持续无监听等条件满足时检查一次；日常运行中断网不会修改代理。

从 CampusFlow Community 升级时，退出旧通用版后运行新版，账号与设置会沿用。点击「保存并启用」更新启动配置；旧最高权限任务仍指向旧文件时，需要按提示授权更新，取消则保留旧路径。

配置与加密凭据位于 `%LOCALAPPDATA%\CampusFlowCommunity\`。遇到问题请阅读[常见问题](FAQ.md)，不要公开账号密码或未经清理的日志。
