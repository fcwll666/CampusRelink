# 常见问题

[返回首页](../README.md) · [安装说明](INSTALLATION.md) · [认证配置](PORTAL-CONFIGURATION.md)

## 适配所有学校吗

目前默认适配南京中医药大学。内置认证方式发送 POST JSON，字段为 `username`、`password` 和 `domain: "default"`，以 `reply_code: 0` 判断认证被接受。

修改接口地址不等于适配另一种认证协议。验证码、扫码、动态挑战、浏览器会话、专有签名等流程需要另外实现。项目与学校、认证厂商之间没有官方隶属或背书关系。

## 网页登录地址和认证接口为什么不一样

`http://net.njucm.edu.cn/portal/index.html` 是供浏览器展示的登录页面；`http://net.njucm.edu.cn/api/portal/v1/login` 是程序提交认证请求的接口。

浏览器页面中的 `wlanuserip`、`wlanacname`、`wlanacip` 等参数描述当前网络环境，不能把他人的完整页面 URL 或 IP 固定写进配置。

不知道接口地址时，可按[如何获取认证接口](PORTAL-CONFIGURATION.md#如何获取认证接口)查看浏览器 Network / 网络中的登录请求，在 Headers / 标头 → General / 常规找到 Request URL / 请求网址。还要确认请求正文和响应与内置 POST JSON 协议兼容；只替换地址不会自动适配其他认证方式。

## 不选 Wi-Fi 也能连接吗

可以。如果 Windows 已经连接校园 Wi-Fi，或电脑使用校园网网线，取消「自动连接 Wi-Fi」后，CampusRelink 只负责该网络上的认证。

需要软件主动连接无线网络时，必须选择这台电脑已保存的 Windows WLAN 配置。列表由当前主机读取；点「搜索 Wi-Fi」可更新附近网络，发布包不包含开发机的 SSID 列表。未保存的网络需要先在 Windows 中连接一次。

## 为什么保存后显示 15 个星号

`***************` 表示已经保存密码，不是真实密码，也不显示其实际长度。保持占位提示或留空且用户名不变时，会沿用原密码；直接输入新密码即可替换，更换用户名则必须输入新密码。

密码由当前 Windows 用户的 DPAPI 加密保存在本机，不能直接复制密文给另一位 Windows 用户使用。

## 显示「联网复检未通过」怎么办

这表示认证已被接受，但外网检测尚未确认成功。程序用不携带账号密码的直接 HTTP 请求访问 `http://www.msftconnecttest.com/connecttest.txt`，要求 HTTP 200 且正文匹配 `Microsoft Connect Test`，不会把门户重定向页当作外网。

可以先等待网络激活，再查看「运行日志」并检查系统当前连接。校园网策略、检测站点受限或临时故障都可能影响结果；认证接受并不等同于所有外网站点已经可达。测试或排障不会因为这个结果在日常运行中自动关闭代理。

提交 Issue 时说明软件版本、Windows 版本、连接方式和去敏后的相关日志。不要公开账号、密码、完整配置文件或未经检查的截图。

## 开机代理修复会影响正在使用的代理吗

它针对上次关机前 VPN 或代理客户端未正确退出、Windows 遗留本机手动代理，但下次开机相应端口没有监听的情况。此时浏览器等使用系统代理的程序可能打不开校园登录页。它只处理全部指向回环地址的手动代理，不是通用 VPN 修复。

启用该选项后，仅在实际开机后前 5 分钟内开始的自启检查中尝试，每次开机最多一次，单轮最多 1 分钟。必须连续三次通过系统代理探测门户均为传输失败，所有本机代理端口持续无监听，且设置未变；备份成功并再次复查后，才关闭手动代理开关、恢复直连与自动检测，保留代理地址及其他配置。有监听的端口、远程代理、收到 HTTP 响应或状态不明时都会保留设置。完整条件见[开机阶段的遗留代理修复](PORTAL-CONFIGURATION.md#开机阶段的遗留代理修复)。

CampusRelink 的认证、门户预取和联网检测使用直连；上述专用门户探测才使用系统代理，三次探测失败不等于三次登录失败。运行中的断网重连、手动测试登录和应用内重新启用后台不触发代理修复。

代理相关记录与备份位于本机数据目录，可能包含私人网络信息，分享前应人工清理。诊断和真实断网测试由使用者在自己的环境中决定；项目自动化测试使用隔离数据和模拟连接，不主动切换真实网络。

## 关闭窗口后怎么还在运行

关闭窗口会收进托盘。要停止本次运行，使用托盘的「退出」；还要取消自启时，使用主界面的「停止后台」。

## 为什么升级后还保留 CampusFlowCommunity 目录

这是为了继续读取此前社区版的加密凭据、设置和自启状态。软件名称与图标已经更新为 CampusRelink，兼容标识保留旧名称。

移动目录或从旧文件名升级后，点一次「保存并启用」。如果应用提示更新最高权限任务路径，同意系统授权后才会更新；取消时旧任务仍指向原程序。
